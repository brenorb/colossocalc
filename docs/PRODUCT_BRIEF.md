# Product Brief: ColossoCalc

## 1. Project Overview / Description

ColossoCalc é uma calculadora web simples desenvolvida para o Cozinha de Pedra como bônus do curso Método Colosso. A aplicação calcula a quantidade diária recomendada de caldo de osso que uma pessoa deve consumir com base no seu peso corporal.

A calculadora utiliza uma regra simples: **para cada 10kg de peso, são necessários 30ml de caldo de osso por dia** para repor a perda natural de colágeno.

## 2. Target Audience

- Alunos do curso Método Colosso
- Pessoas interessadas em consumir colágeno natural através do caldo de osso
- Usuários que buscam uma ferramenta prática e rápida para calcular sua dosagem diária

## 3. Primary Benefits / Features

- **Cálculo instantâneo**: Entrada do peso e cálculo imediato da dosagem diária
- **Simplicidade**: Interface única e direta, sem complexidade desnecessária
- **Acessibilidade**: Página estática que funciona offline após carregamento inicial
- **Bônus do curso**: Valor agregado para alunos do Método Colosso

## 4. High-Level Tech/Architecture

- **Arquitetura**: Página estática single-page application (SPA)
- **Lógica**: 100% client-side (JavaScript)
- **Deploy**: Hospedagem estática (GitHub Pages)
- **Design**: Inspirado no site do Método Colosso (https://metodocolosso.com.br/)
- **Idioma**: Português (Brasil)

### Fórmula de Cálculo
```
Dosagem diária (ml) = (Peso em kg / 10) × 30
```
