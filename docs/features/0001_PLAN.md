# Technical Plan: ColossoCalc - Bone Broth Dosage Calculator

## Description

ColossoCalc é uma calculadora web estática de página única que calcula a dosagem diária recomendada de caldo de osso com base no peso corporal do usuário. A aplicação é 100% client-side, sem dependências de backend ou banco de dados.

## Files to Create

### `index.html`
- Estrutura HTML5 semântica
- Meta tags para responsividade e SEO
- Container principal para a calculadora
- Campo de entrada numérica para peso (em kg)
- Botão de calcular
- Área de exibição do resultado
- Elementos visuais inspirados no design do Método Colosso (logo, cores)

### `styles.css` (ou estilos inline/integrado)
- Design inspirado no site metodocolosso.com.br
- Esquema de cores: vermelho (#hex do site) como cor primária
- Tipografia moderna e legível
- Layout responsivo (mobile-first)
- Estilização do campo de entrada, botão e área de resultado
- Animações sutis para feedback visual

### `script.js` (ou JavaScript inline/integrado)
- Função de cálculo: `calculateDosage(weight)`
- Validação de entrada (peso deve ser número positivo)
- Atualização dinâmica do DOM com resultado
- Formatação do resultado (ml com casas decimais apropriadas)
- Tratamento de erros (entrada inválida, valores negativos, etc.)

## Algorithm: Cálculo de Dosagem

1. Receber peso do usuário em quilogramas (kg)
2. Validar entrada:
   - Deve ser um número válido
   - Deve ser maior que zero
   - Opcional: definir limite máximo razoável (ex: 300kg)
3. Aplicar fórmula: `dosagem_ml = (peso_kg / 10) × 30`
4. Arredondar resultado para 1 casa decimal (ou número inteiro, conforme UX)
5. Exibir resultado formatado: "X ml de caldo de osso por dia"

## Implementation Details

### HTML Structure
- Header com logo/título "ColossoCalc"
- Seção principal com:
  - Label e input para peso
  - Botão "Calcular"
  - Div para exibição do resultado
- Footer opcional com informações do Método Colosso

### CSS Styling
- Cores: vermelho primário (#DC2626 ou similar do site), branco, cinza para texto
- Fonte: sans-serif moderna (similar ao site de referência)
- Espaçamento e padding consistentes
- Botão com hover state
- Input com focus state
- Resultado destacado visualmente

### JavaScript Logic
- Event listener no botão de calcular
- Event listener opcional no campo de entrada (Enter key)
- Função `calculateDosage()`:
  - Input: peso (number)
  - Output: dosagem em ml (number)
  - Validação antes do cálculo
- Função `displayResult()`:
  - Recebe valor calculado
  - Formata para exibição
  - Atualiza DOM
- Função `validateInput()`:
  - Verifica se é número
  - Verifica se é positivo
  - Retorna boolean ou lança erro

### Edge Cases
- Entrada vazia: mostrar mensagem de erro amigável
- Entrada não numérica: mostrar mensagem de erro
- Peso zero ou negativo: mostrar mensagem de erro
- Peso muito alto: calcular normalmente ou mostrar aviso (opcional)
