# Technical Plan: Suprimir Mensagens de Erro em Inglês do HTML5

## Description

Atualmente, quando o usuário insere valores inválidos no campo de peso (como valores negativos), o navegador exibe mensagens de erro em inglês através da validação HTML5 nativa (ex: "Value must be greater than or equal to 0."). Essas mensagens aparecem em tooltips nativos do navegador antes da validação JavaScript customizada em português ser executada. Esta feature suprime completamente essas mensagens nativas e garante que apenas as mensagens de erro customizadas em português sejam exibidas.

## Files to Modify

### `index.html`
- Adicionar atributo `novalidate` ao elemento `<form id="calculator-form">` para desabilitar a validação HTML5 nativa do navegador

### `script.js`
- A função `handleCalculate()` já previne o comportamento padrão com `event.preventDefault()`, mas precisa garantir que nenhuma validação HTML5 seja executada
- Verificar se há necessidade de prevenir eventos adicionais que possam disparar validação nativa (ex: eventos de input, blur)

## Implementation Details

### HTML Changes
- O formulário deve ter o atributo `novalidate` adicionado para desabilitar completamente a validação HTML5 nativa
- Os atributos `min="0"`, `required`, e `type="number"` podem permanecer no input para manter a semântica e acessibilidade, mas não causarão validação visual nativa

### JavaScript Behavior
- A função `handleCalculate()` já executa `event.preventDefault()` que previne o submit padrão
- Com `novalidate` no formulário, mesmo que o submit padrão seja tentado, não haverá validação HTML5
- A validação JavaScript customizada através de `validateInput()` continuará funcionando normalmente
- As mensagens de erro em português continuarão sendo exibidas através de `displayResult()`

## Algorithm

1. Adicionar `novalidate` ao formulário no HTML
2. O navegador não executará validação HTML5 nativa ao submeter o formulário
3. Apenas a validação JavaScript customizada (`validateInput()`) será executada
4. Apenas mensagens de erro em português serão exibidas através de `displayResult()`

## Edge Cases

- Valores negativos: não mostrará mais tooltip em inglês, apenas mensagem customizada em português
- Campo vazio: não mostrará mais tooltip em inglês do `required`, apenas mensagem customizada em português
- Valores inválidos (não numéricos): não mostrará mais tooltip em inglês do `type="number"`, apenas mensagem customizada em português
- Valores abaixo do mínimo: não mostrará mais tooltip em inglês do `min="0"`, apenas mensagem customizada em português
