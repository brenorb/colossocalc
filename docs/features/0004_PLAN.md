# Technical Plan: Correção de Layout - ML Sempre Abaixo do Texto Principal

## Description

Em alguns casos, especialmente quando o texto principal é longo ou em telas menores, o texto dos mililitros (ml) aparece ao lado do texto principal ao invés de abaixo. Esta feature corrige o layout para garantir que o ml sempre apareça em uma nova linha abaixo do texto principal das xícaras.

## Files to Modify

### `script.js`
- Modificar função `displayResult()` para garantir que o ml apareça em uma nova linha abaixo do texto principal
- Adicionar quebra de linha (`<br>`) antes do span com os ml, ou estruturar o HTML de forma que o ml seja um elemento de bloco

### `styles.css`
- Adicionar ou modificar estilo da classe `.result-secondary` para garantir que o ml apareça em uma nova linha
- Considerar usar `display: block` ou garantir que o elemento anterior tenha `display: block` para forçar quebra de linha

## Implementation Details

### Problema Atual

No código atual (linhas 176-186 de `script.js`), o ml é adicionado como um span inline após um espaço em branco:
- O texto das xícaras é adicionado em um span
- Um espaço em branco é adicionado como texto
- O ml é adicionado em um span com classe `result-secondary`

Quando o texto principal é longo, o navegador pode fazer wrap natural e o ml pode aparecer ao lado ao invés de abaixo.

### Solução

Garantir que o ml sempre apareça em uma nova linha abaixo do texto principal. Duas abordagens possíveis:

**Abordagem 1: Adicionar `<br>` antes do ml**
- Inserir um elemento `<br>` antes do span com os ml
- Garantir que o ml apareça sempre em uma nova linha

**Abordagem 2: Usar CSS para forçar quebra**
- Modificar CSS para fazer o span com ml ser `display: block`
- Ou fazer o span das xícaras ser `display: block` e o ml também

### Recomendação

Usar Abordagem 1 (adicionar `<br>`) pois é mais explícita e garante o comportamento desejado independente do CSS. A Abordagem 2 pode ser complementar para garantir consistência visual.

## Algorithm

1. Na função `displayResult()`, após criar o span com o texto das xícaras
2. Adicionar um elemento `<br>` antes de criar o span com os ml
3. Opcionalmente, modificar CSS para garantir que `.result-secondary` seja `display: block` ou que o elemento anterior force quebra de linha

## Edge Cases

- Texto muito curto: ml ainda deve aparecer abaixo (não ao lado)
- Texto muito longo: ml deve aparecer abaixo mesmo que o texto principal quebre em múltiplas linhas
- Telas muito pequenas: layout deve permanecer consistente
- Quando há aviso (warning): o aviso já usa `<br>` e aparece abaixo, então o ml deve aparecer acima do aviso
