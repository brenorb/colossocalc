# Technical Plan: Exibição de Dosagem em Xícaras como Formato Principal

## Description

Atualmente, a calculadora exibe a dosagem apenas em mililitros (ml) como formato único. Esta feature adiciona a exibição em xícaras como formato principal, mantendo os mililitros como informação secundária com menor relevância visual. A conversão utiliza 1 xícara = 200ml, arredondando para cima para números inteiros ou meias xícaras (ex: "uma xícara e meia", "duas xícaras"). Não serão usados valores decimais como 2,3 xícaras.

## Files to Modify

### `script.js`
- Adicionar constante `CUPS_PER_ML` (1 xícara = 200ml)
- Criar função `mlToCups(ml)` para converter mililitros em xícaras
- Criar função `formatCups(cups)` para formatar o número de xícaras em texto em português (ex: "uma xícara", "uma xícara e meia", "duas xícaras")
- Modificar função `formatResult(dosage)` para exibir xícaras como formato principal e ml como secundário
- A função `calculateDosage()` permanece inalterada (continua retornando ml)

### `styles.css`
- Adicionar classe CSS para o texto secundário (ml) com menor destaque visual (menor tamanho de fonte, cor mais clara)
- Manter estilo atual para o texto principal (xícaras)

## Implementation Details

### Conversão de ML para Xícaras

1. Converter ml para xícaras: `cups = ml / 200`
2. Arredondar para cima para o próximo múltiplo de 0.5 (meia xícara):
   - Usar `Math.ceil(cups * 2) / 2` para arredondar para cima para a meia xícara mais próxima
   - Exemplos:
     - 150ml → 0.75 xícaras → arredondado para 1 xícara
     - 250ml → 1.25 xícaras → arredondado para 1.5 xícaras
     - 300ml → 1.5 xícaras → permanece 1.5 xícaras
     - 350ml → 1.75 xícaras → arredondado para 2 xícaras

### Formatação de Texto em Português

A função `formatCups(cups)` deve retornar:
- "uma xícara" para 1.0
- "uma xícara e meia" para 1.5
- "duas xícaras" para 2.0
- "duas xícaras e meia" para 2.5
- "três xícaras" para 3.0
- E assim por diante...

### Exibição do Resultado

A função `formatResult(dosage)` deve retornar HTML estruturado ou texto formatado que:
1. Exibe o número de xícaras como texto principal (em destaque)
2. Exibe os mililitros como texto secundário (menor, menos destacado)
3. Formato sugerido: "uma xícara e meia de caldo de osso por dia (300 ml)"

### Estilos CSS

- Criar classe `.result-secondary` ou similar para o texto de ml com:
  - Tamanho de fonte menor (ex: 0.875rem ou 1rem)
  - Cor mais clara (ex: `var(--text-light)`)
  - Peso de fonte normal (não bold)

## Algorithm

1. Calcular dosagem em ml usando `calculateDosage(weight)` (já existente)
2. Converter ml para xícaras: `cups = ml / 200`
3. Arredondar para cima para múltiplo de 0.5: `roundedCups = Math.ceil(cups * 2) / 2`
4. Formatar xícaras em texto português usando `formatCups(roundedCups)`
5. Formatar ml mantendo 1 casa decimal (como está atualmente)
6. Combinar ambos os formatos na exibição, com xícaras em destaque e ml secundário

## Edge Cases

- Dosagem muito pequena (< 100ml): arredondar para pelo menos "meia xícara" ou "uma xícara" dependendo do valor
- Dosagem exata em múltiplos de 200ml: exibir como número inteiro de xícaras (ex: 200ml = "uma xícara")
- Dosagem entre múltiplos: arredondar para cima para a meia xícara mais próxima
- A função `displayResult()` precisa ser atualizada para lidar com o novo formato que pode incluir HTML (spans com classes diferentes)
