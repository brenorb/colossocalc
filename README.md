# ColossoCalc

Calculadora web simples para calcular a quantidade diária recomendada de caldo de osso com base no peso corporal. Desenvolvida como bônus do curso Método Colosso da Cozinha de Pedra.

## 🎯 Público-Alvo

- Alunos do curso Método Colosso
- Pessoas interessadas em consumir colágeno natural através do caldo de osso
- Usuários que buscam uma ferramenta prática e rápida para calcular sua dosagem diária
